# SMBIOS и Apple ID

## Почему MacBookAir9,1

`MacBookAir9,1` — это MacBook Air 2020 года с процессором десятого поколения и только встроенной графикой.
Из поддерживаемых моделей это ближайшее к четырёхъядерному ноутбуку на Comet Lake с UHD 630 и без пригодной
дискретной карты, и она даёт разумные значения по умолчанию для управления питанием и графики.

Варианты `MacBookPro16,x` подразумевают дискретную графику AMD, которой здесь нет.

## Сгенерировать свои значения — обязательно

В приложенном `config.plist` эти поля намеренно обнулены:

```
SystemSerialNumber = CHANGEME
MLB                = CHANGEME
SystemUUID         = 00000000-0000-0000-0000-000000000000
ROM                = 00 00 00 00 00 00
```

**Пока вы их не заполните, система нормально не заработает.** Не берите значения из репозиториев, включая
этот: продублированный серийник хуже случайного.

Пользуйтесь [macserial](https://github.com/acidanthera/OpenCorePkg/releases) — он идёт в составе OpenCore,
в `Utilities/macserial`:

```bash
macserial -m MacBookAir9,1 -n 1
```

Он печатает согласованную пару «серийник + MLB». Дальше:

| Поле | Значение |
|---|---|
| `SystemSerialNumber` | серийник от `macserial` |
| `MLB` | серийник платы из той же строки — **это должна быть пара из одной строки** |
| `SystemUUID` | любой случайный UUID (`uuidgen`), лишь бы уникальный |
| `ROM` | **реальный MAC вашего сетевого адаптера**, шестью байтами |

`ROM` важен. Службы Apple выводят из него часть идентичности устройства, и значение, не совпадающее с
настоящим железом, — частая причина отказов iServices. Посмотрите его через `ifconfig` на встроенном
проводном или беспроводном интерфейсе.

### Проверьте, что серийник не принадлежит настоящему Mac

Вставьте сгенерированный серийник на [странице проверки Apple](https://checkcoverage.apple.com/). Вам нужно,
чтобы его отвергли как **недействительный**. Если Apple его узнала — он принадлежит реальной машине,
генерируйте другой.

## Проверка board-ID

Свежие macOS отказываются устанавливаться на некоторые модели SMBIOS. Вместо `-no_compat_check` здесь
используется аккуратный путь, уже настроенный в `config.plist`:

- `Booter → Patch → «Skip Board ID check»` — **включён**
- `NVRAM → 4D1FDA02-… → revpatch = auto,sbvmm` вместе с `RestrictEvents.kext`

`SecureBootModel` — `Disabled`.

## Тонкость про NVRAM

`NVRAM → Add` в OpenCore записывает переменную, **только если её ещё нет**. Переменные, перечисленные в
`NVRAM → Delete`, сначала стираются, поэтому применяются заново каждую загрузку; все остальные остаются
такими, какими были записаны когда-то раньше.

На этом спотыкаются с `csr-active-config`. Здесь его нет в списке `Delete`, поэтому правка в `config.plist`
ничего не изменит на машине, где значение в NVRAM уже есть. Чтобы действительно поменять SIP, нужно либо
добавить ключ в `NVRAM → Delete`, либо сбросить NVRAM.

Стоит проверять, что у вас на самом деле:

```bash
nvram csr-active-config
csrutil status
```

## Apple ID

**iCloud, App Store и обновления работают.** Почта, диск, заметки, фото — всё нормально.

**«Найти Mac» включать не надо.** На настоящем железе эта функция ставит блокировку активации, привязанную
к идентичности машины. На хакинтоше она не может работать как задумано, но способна записать состояние
блокировки в NVRAM. Приобрести нечего, потерять есть что.

**iMessage и FaceTime ненадёжны** на хакинтошах с картами Intel и часто не активируются. Повторяющиеся
неудачные попытки активации — одна из причин, по которым Apple помечает учётные записи. Если хотите
попробовать, возьмите отдельную учётную запись, а не основную, и не долбитесь в активацию многократно.

## После смены SMBIOS сделайте две вещи

Смена серийников заставляет macOS считать машину новым железом:

1. **Сбрасываются настройки питания.** Заново примените весь [блок настроек сна](sleep-hibernation.md) и
   проверьте результат.
2. **Обнуляется кэш настроек Bluetooth.** Удалите `/Library/Preferences/com.apple.Bluetooth.plist` и
   соответствующий `~/Library/Preferences/ByHost/com.apple.Bluetooth.*.plist`, затем выключите машину
   полностью.

И то и другое выяснялось долгим путём.
